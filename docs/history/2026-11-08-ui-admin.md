# 2026-11-08 — Normalisasi UI Admin

## Tujuan
Mengganti halaman admin yang masih HTML polos dengan pola visual proyek:
page head, filter bar, tabel, kartu, form, badge, dan empty state.

## Perubahan
- Dashboard: kartu KPI per role, aksi cepat, log aktivitas, antrean khusus, tugas teknisi.
- Pengguna: tabel + filter, form tambah/ubah dengan layout form admin.
- Inspeksi: tabel + filter, form catat inspeksi.
- Maintenance: tabel + filter status/pencarian, form buat/ubah/selesai.
- Laporan: kartu KPI, tabel utilisasi, peminjam teratas, kerusakan terbaru, ekspor.
- Pengaturan: form identitas organisasi dan kebijakan.
- Serah terima: form kondisi per unit dengan tabel dan info booking.
- Badge status maintenance ditambahkan ke komponen `status-badge`.
- CSS: KPI grid, breadcrumb, bell, section title.
