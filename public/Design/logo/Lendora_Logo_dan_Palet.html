01 — Logo

Sistem Logo Lendora

Satu geometri dasar untuk semua kebutuhan: ikon aplikasi, favicon, lockup horizontal, dan lockup bertumpuk. Klik tombol di setiap kartu untuk mengunduh.

Konsep: “L” + panah serah-terima

Huruf L (Lendora) dengan goresan tumpul yang diujungnya berubah menjadi panah — gerak menyerahkan barang saat peminjaman dan mengembalikannya setelah selesai. Sesuai siklus bisnis Lendora: Request → Pickup → Return → Available.

  • Bold & sederhana — tetap terbaca pada favicon 16 px maupun spanduk besar.
  • Netral aset — bukan ikon kamera, sehingga tetap relevan saat platform berkembang ke jenis aset lain.
  • Flat tanpa gradasi — satu warna brand #F97316 + putih, sesuai arah Clean Professional.

Variasi logo

Ukuran PNG mengikuti pilihan di bawah (lebar untuk lockup, sisi untuk ikon).

Logo negatif (putih + oranye)

Versi terbalik untuk ditempatkan di atas blok oranye brand, mis. sampul modul atau stiker peralatan.

Logo monokrom

02 — Palet Warna

Palet Warna Lendora

Token berlabel Acuan berasal dari Panduan Arahan AI; Usulan adalah pelengkap yang umum dibutuhkan aplikasi dan perlu disetujui pemilik proyek. Klik swatch apa pun untuk menyalin kode HEX.

Keluarga Orange — skala brand

Intensitas aksen dari tint lembut hingga deep.

Warna netral

Putih & netral mendominasi halaman; orange hanya aksen.

Warna status

Dibedakan dari warna brand — dipakai untuk badge, banner, dan status transaksi/aset.

Unduh palet

Gambar palet untuk dokumentasi, atau file token untuk langsung dipakai di kode.

Gambar palet (PNG)

Brand board resolusi tinggi berisi logo + seluruh token warna. Cocok ditempel di dokumen desain atau folder public/Desain/.

Token CSS Variables

Semua warna sebagai --ld-* di :root — siap ditempel ke stylesheet Laravel/Blade.

Token JSON & Tailwind

lendora-tokens.json (untuk tooling/design pipeline) dan tailwind.colors.js (extend theme Tailwind).

Salin cepat

Butuh beberapa warna sekaligus? Salin daftar HEX lengkap ke clipboard dalam satu klik.
